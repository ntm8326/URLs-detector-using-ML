# Nhóm 4 - Special Characters

#feature

## Mô tả

> Đếm số lượng các ký tự đặc biệt trong URL và các thành phần

## Danh sách Features

| Feature | Mô tả |
|---------|-------|
| `hyphen_in_subdomain` | Số dấu `-` trong subdomain |
| `hyphen_in_domain` | Số dấu `-` trong domain |
| `unicode` | Có ký tự Unicode trong domain |
| `punycode` | Có prefix `xn--` (Punycode) |
| `at_sign_in_netloc` | Số dấu `@` trong netloc |
| `slash_in_path` | Số dấu `/` trong path |
| `dot_in_path` | Số dấu `.` trong path |
| `strange_in_query` | Số ký tự lạ trong query |
| `equal_in_query` | Số dấu `=` trong query |
| `ampersand_in_query` | Số dấu `&` trong query |
| `number_subdomain` | Số lượng subdomain (đếm dấu chấm + 1) |
